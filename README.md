# Python Calculator

A desktop calculator application with a graphical user interface for basic arithmetic operations.

## Features
- Addition, subtraction, multiplication, division
- Tkinter-based GUI
- Clean and responsive interface

## Tech Stack
- **Language:** Python
- **Library:** Tkinter

## How to Run
python calculator.py
